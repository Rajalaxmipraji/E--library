# 🎓 E-Library with Secure PDF Access

A college E-Library web application that allows students to securely view, manage, and access study PDFs online.

---

## 🚀 Features
- Department-wise book organization
- Secure login system (JWT-based)
- Protected PDF access (only logged-in users)
- MySQL database integration
- Node.js + Express backend
- Simple HTML/CSS/JS frontend

---

## 🧰 Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** MySQL  
**Authentication:** JWT
